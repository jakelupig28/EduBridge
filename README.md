# EduBridge

EduBridge is a Compose-based Android app showcasing authentication, course browsing, quizzes, and learning progress UI screens.

## Run (Windows PowerShell)

```powershell
cd C:\Users\Administrator\AndroidStudioProjects\EduBridge
./gradlew.bat assembleDebug
```

Open the project in Android Studio to run on an emulator/device and view Compose previews.
